# Advent of Code solutions

My Python solutions for [Advent of Code](https://adventofcode.com/), one folder per year.

## Inputs are not included

Advent of Code asks that puzzle text and inputs are not redistributed, so this repository
contains **solution code only**. Puzzle inputs are kept in a private submodule that is not
accessible to you.

To run a solution, pass **your own** puzzle input file as the first command-line argument.
